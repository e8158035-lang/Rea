# مختبر التحليل الثابت REA (نسخة Termux المحلية)

> **تنبيه قانوني:** هذه الأداة مخصصة حصريًا لتحليل التطبيقات والملفات التي يملكها المستخدم أو لديه إذن صريح بتحليلها.

## المزايا الرئيسية
- **الرفع المتدفق للملفات الكبيرة (500MB+):** حفظ مقسم على القرص مباشرة بدون تحميل الملف في الذاكرة، مع تتبع التقدم لحظياً عبر SSE.
- **حماية أمنية كاملة:** منع هجمات Zip Slip، وتقييد عمق الضغط المتداخل وأحجام فك الضغط لمنع استنزاف التخزين، وتنظيف الملفات المؤقتة تلقائياً بعد بناء الأرشيف النهائي.
- **تحديد النوع عبر التوقيع الثنائي (Magic Bytes):** تمييز فعلي بين EXE (Native PE / .NET / Electron / PyInstaller / NSIS) وAPK وXAPK/APKS/APKM وZIP.
- **دمج الحزم المقسّمة (Split APKs):** استخراج جميع ملفات APK (`base.apk` + `config.*`) ودمج `lib/` و`res/` بالكامل وقراءة `manifest.json`.
- **اكتشاف أطر العمل:** Flutter (`libflutter.so`, `flutter_assets`, `libapp.so` مع `blutter`/`reFlutter` عند توفرها وذكر التقييد صراحة عند غيابها)، React Native، Unity، Xamarin.
- **فصل صارم بين كود التطبيق ومكتبات الطرف الثالث:** كل دالة وشاشة ونص وصلاحية مرتبطة بدليل صريح (مسار الملف أو الكلاس)، بدون نصوص قوالب أو أرقام مختلقة.
- **حفظ الأصل والتحقق التلقائي:** نسخ بايت ببايت في `original/` مع ملف `.sha256` لكل ملف والتحقق التلقائي في نهاية المعالجة.
- **إعادة بناء صادقة:** إخراج `rebuilt_project/` وملف `README_REBUILT.md` يوضح ما تم استرداده وما ينقصه بوضوح.

## فحص الأدوات والاختبار الذاتي
```bash
bash setup_check.sh
python tests/self_test_xapk.py
```

## تشغيل الخادم المحلي
```bash
python app.py
```
يفتح الخادم افتراضياً على: `http://127.0.0.1:5000`
